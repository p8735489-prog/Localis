# Localis v47 — Chat interactions

- Long-press any chat message to copy it and open contextual actions.
- Assistant messages expose Regenerate response.
- Assistant messages expose Choose another AI, routed to model selection.
- Chat list uses a Material 3 floating jump-to-latest action after scrolling away from the newest messages.
- The list follows new messages and uses smooth animated scrolling.
- Regeneration removes the previous assistant turn and re-runs the preceding user turn without duplicating the user message in the context.
- Added localized strings for all supported locales.
